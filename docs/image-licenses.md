## 6. Social Sharing & OpenGraph Image Specification

Every indexable page on `https://nashik.sooubh.in` generates standard OpenGraph (`og:image`) and Twitter Card (`twitter:image`) metadata via `constructMetadata` in `src/lib/seo.ts`:

- **Dimensions**: Strictly configured as `1200 × 630` pixels (standard 1.91:1 ratio for Facebook, Twitter/X summary_large_image, WhatsApp, LinkedIn, and iMessage previews).
- **Format**: High-fidelity modern WebP (`image/webp`) with fallback image headers.
- **Alt Text**: Contextual descriptive alternative text describing the landmark, region, or itinerary.
- **Protocol**: Absolute HTTPS URL referencing canonical domain `https://nashik.sooubh.in`.

## 7. Zero Hotlinking Policy Verification

- **External Image Prohibition**: All image assets served across web routes and components must reside locally within `public/`.
- **Automated Verification**: Build script `scripts/audit-images.mjs` scans all TypeScript, TSX, CSS, and Markdown source files. Any external `http://` or `https://` image link triggers a non-zero exit code.
- **Audit Result (2026-11-24)**: Verified 0 external hotlinked image references across the entire repository.
